# Phase 3 — deferred until after feedback

Do not implement any of these until:
- You and your loved one have used v1.0 for 30 days
- Beta testers have given feedback
- At least 3 users have explicitly asked for the feature

## Candidate features (none pre-approved)

### Correlation insights
- Only show after ≥ 60 days of data AND ≥ 5 logged cycles
- Always display sample size
- Always display "correlation, not causation" line
- Never say "X causes Y" or "X improves Y"
- User must be able to turn off insight generation entirely
- Reviewed by a statistician before shipping

### Habit nudges (NOT streaks)
- No "you broke your streak"
- No counters that reset on miss
- Only: "Want to log today?" (once per day max)
- Fully disableable

### Weight tracking
- Requires ED-informed design review with a clinician
- Default: hidden
- User must opt in explicitly
- No BMI shown
- No goal weights
- No "you lost X" celebrations
- No trend lines without context text

### Apple Health / Google Fit
- Optional, never default-on
- Read-only for phase/cycle data (write is a privacy risk)
- Requires dedicated privacy review

### Cloud backup
- Requires end-to-end encryption before shipping
- Requires explicit opt-in
- Requires clear "what gets uploaded" explanation
- Requires a delete-from-cloud flow

### AI features
- Not until a dedicated safety review process exists
- Not until you can show the model's boundaries to a clinician
- Probably never for the education content (bundled, reviewed copy
  is safer)

## Rejected outright
- Ovulation prediction
- "Days until your period" counts
- Fertile window estimation
- PCOS "score" or "severity index"
- Ads
- Data sale
- Any feature that shames irregularity
