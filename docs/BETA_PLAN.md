# Beta plan

Before v1.0, run a beta with 3–5 real users for 14+ days.

## Who to recruit
- Your loved one (already using it)
- 2–4 people from PCOS communities (Reddit r/PCOS, local support
  groups, friends of friends)
- If possible, at least one person whose symptoms are *different* from
  your loved one's — PCOS is heterogeneous and you'll miss edge cases
  if you only test with one phenotype

## How to distribute
- Android: use Play Store Internal Testing track (free, up to 100
  testers, no review needed)
- iOS: use TestFlight (requires Apple Developer account, ~$99/year)

## What to ask them
Weekly check-in via a simple form:
- Did you open Lunora every day this week? If not, which days and why?
- What did you try to do and couldn't?
- What feature did you use most? Least?
- Did anything feel confusing, shaming, or overwhelming?
- Would you recommend it to a friend with PCOS? Why/why not?

## What counts as a "critical issue" (blocks 1.0)
- Data loss on any device
- Crash on app launch
- Any feature that shows ovulation / "late" / "you're X days behind"
- Any feature that recommends a specific dose or treatment
- Any feature that shows weight loss claims or "bad food" labels

## Success criteria for 1.0
- ≥ 3 of 5 testers open the app 5+ days per week, unprompted
- 0 critical issues in a full week
- At least one tester says "I would keep using this"
- At least one piece of feedback you disagree with (means they're
  actually using it enough to form opinions)
